# Requisitos do Sistema

**Versão:** 1.0
**Data:** 22/07/2026
**Status:** Em desenvolvimento

## Requisitos Funcionais

### RF01 - Exibição de produtos

O sistema deve permitir que o cliente visualize os produtos disponíveis para compra.

### RF02 - Adicionar produto ao carrinho

O sistema deve permitir o cliente adicione produtos ao carrinho.

### RF03 - Alterar quantidade de produtos

O sistema deve permitir que o cliente aumente ou diminua a quantidade dos produtos adicionados ao carrinho.

### RF04 - Remover produto do carrinho

O sistema deve permitir que o cliente remova produtos adicionados ao carrinho.

### RF05 - Visualizar produtos no carrinho

O sistema deve permitir que o cliente visualize os produtos adicionados ao carrinho antes de finalizar o pedido.

### RF06 - Envio do pedido pelo WhatsApp

O sistema deve permitir que o cliente envie o pedido finalizado para o WhatsApp do proprietário da doceria.

### RF07 - Validação de carrinho vazio

O sistema deve informar ao cliente que o carrinho está vazio quando ele tentar finalizar um pedido sem possuir produtos adicionados.

### RF08 - Atualização de valor do pedido

O sistema deve atualizar o valor total do pedido de acordo com a quantidade e os produtos adicionados ao carrinho.
